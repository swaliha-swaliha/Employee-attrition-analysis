# Employee Attrition Analysis

## 📌 Project Overview
This project analyzes employee attrition data to identify key factors influencing employee turnover.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Key Insights
- Overtime employees have higher attrition rate
- Low job satisfaction increases turnover risk
- Monthly income impacts retention

## 📁 Dataset
HR Employee Attrition Dataset

## 🚀 Conclusion
This analysis helps organizations understand and reduce employee attrition.
